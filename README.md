# City Widget

Одностраничный виджет погоды и городской афиши. Погода загружается из Open-Meteo, события на сегодня — из TimePad с KudaGo как дополнительным источником.

## Запуск

```bash
npm install
npm run dev
```

Для production-сборки: `npm run build`.

Для загрузки афиши нужен серверный токен TimePad. Скопируйте `.env.example` в `.env.local` и укажите `TIMEPAD_API_TOKEN`. Токен не попадает в клиентскую сборку. Без него список покажет ошибку API и кнопку повтора.

## Запуск на сервере

На Ubuntu-сервере создайте `.env` из `.env.example`, задайте `TIMEPAD_API_TOKEN`, затем выполните:

```bash
docker compose up -d --build
```

После запуска сайт доступен по HTTP на IP сервера. Nginx отдаёт production-сборку и проксирует запросы к TimePad и KudaGo. Секрет TimePad хранится только в окружении контейнера и добавляется к серверному запросу.

## Что внутри

- Погода и прогноз на 5 дней для Москвы, Санкт-Петербурга, Казани, Махачкалы и Каспийска.
- Отдельная страница погоды с почасовым прогнозом и лёгкой погодной анимацией.
- События выбранного города на текущую дату из TimePad и KudaGo.
- Поиск по названию/площадке, категории, сортировка и карточки с переходом к источнику.
- Избранное и тема сохраняются в `localStorage`.
- Блок планов дня: событие в фокусе, подсказка по погоде, бесплатные события и ближайшее начало.
- Адаптивная вёрстка, состояния загрузки и ошибки с повторным запросом.
- Клавиатурное управление, заметный фокус и доступный диалог события.
- `/weather-preview` — интерактивный предпросмотр погодных эффектов.

## Структура исходников

- `src/app` — корневое приложение и разбор маршрутов.
- `src/components` — общая шапка и погодные эффекты.
- `src/features` — экраны и компоненты погоды, афиши, планов дня и событий.
- `src/domain` — модели данных и преобразование записей афиши.
- `src/services` — запросы к Open-Meteo, TimePad и KudaGo.
- `src/hooks` — загрузка данных выбранного города.
- `src/config` и `src/utils` — списки городов, категории, форматирование дат и локальное хранилище.
- `src/styles` — базовые стили, компоненты афиши и стили экранов приложения. Порядок подключения сохраняет каскад интерфейса.

В проекте не настроена отдельная команда тестирования или линтер. Перед выпуском доступна строгая проверка TypeScript и production-сборка командой `npm run build`.

Источники: [Open-Meteo](https://open-meteo.com/), [TimePad API](https://api.timepad.ru/) и [KudaGo API](https://docs.kudago.com/api/).
