# City Widget

Погода и события города на одном экране.

## Запуск локально

```bash
npm install
npm run dev
```

## Запуск на сервере

Сайт раздаёт Nginx из собранной версии проекта. Запустить Nginx:

```bash
sudo systemctl start nginx
```

Чтобы Nginx запускался автоматически после перезагрузки сервера:

```bash
sudo systemctl enable nginx
```

Для публикации новой версии выполните `npm run build` и разместите содержимое папки `dist` в каталоге сайта на сервере. Токен TimePad хранится в настройках сервера и не входит в репозиторий.

## Что внутри

- **Погода:** текущая температура, ощущается как, влажность, ветер и прогноз на 5 дней. Можно выбрать Москву, Санкт-Петербург, Казань, Махачкалу или Каспийск.
- **Экран погоды:** почасовой прогноз и анимация погодных условий, которая меняется вместе с погодой выбранного города.
- **Афиша на сегодня:** события из TimePad и KudaGo с фильтрами по категориям, поиском по названию и площадке, сортировкой по времени, цене и популярности.
- **Карточки событий:** подробности события открываются поверх списка; можно перейти к странице события у источника и добавить его в избранное.
- **План дня:** ближайшие события, бесплатные варианты и подсказки, учитывающие погоду.
- **Избранное и тема:** сохраняются в браузере и остаются после перезагрузки страницы.
- **Состояния интерфейса:** загрузка, сообщение об ошибке API с повторным запросом, адаптивная вёрстка, управление с клавиатуры и заметный фокус.
- **Предпросмотр эффектов:** `/weather-preview` показывает погодную анимацию для разных условий.

Погода: [Open-Meteo](https://open-meteo.com/). События: [TimePad](https://api.timepad.ru/) и [KudaGo](https://docs.kudago.com/api/).
