# Городской карман

Одностраничный виджет погоды и городской афиши. Погода загружается из Open-Meteo, события и киносеансы на сегодня — из открытого API KudaGo.

## Запуск

```bash
npm install
npm run dev
```

Для production-сборки: `npm run build`.

## Что внутри

- Погода и прогноз на 5 дней для Москвы, Санкт-Петербурга и Казани.
- События и киносеансы выбранного города на текущую дату.
- Поиск по названию/площадке, категории, сортировка и карточки с переходом к источнику.
- Избранное и тема сохраняются в `localStorage`.
- Блок планов дня: событие в фокусе, подсказка по погоде, бесплатные события и ближайшее начало.
- Адаптивная вёрстка, состояния загрузки и ошибки с повторным запросом.
- Клавиатурное управление, заметный фокус и доступный диалог события.

Источники: [Open-Meteo](https://open-meteo.com/) и [KudaGo API](https://docs.kudago.com/api/).
